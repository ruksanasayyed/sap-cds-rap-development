# 🧩 SAP CDS & RAP | Modern Application Development

> Exploring modern SAP application development through data modelling, service exposure and business application design.

## About This Repository

This repository documents my learning and practical experiments with SAP Core Data Services (CDS) and the ABAP RESTful Application Programming Model (RAP).

The objective is to understand how modern SAP applications are designed, developed and exposed as business services.

## Learning Areas

- CDS View Entities
- Associations and Annotations
- Data Modelling
- Virtual Data Models
- Behavior Definitions
- Behavior Implementations
- Business Objects
- Service Definitions
- Service Bindings
- OData Services
- RAP Application Development
- SAP Fiori Elements
- Clean Core Principles
